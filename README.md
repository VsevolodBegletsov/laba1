Toolkit Беглецова Всеволода с калькулятором и конвертером!!

Функционал:

python -m toolkit calc "МАТЕМАТИЧЕСКОЕ ВЫРАЖЕНИЕ" - посчитать любое допустимое математическое выражение с использованием символов "+", "-", "*", "/", "//", "%"

python -m toolkit convert "ЧИСЛО" --from "СИСТЕМА ИЗМЕРЕНИЙ 1" --to "СИСТЕМА ИЗМЕРЕНИЙ 2" - сконвертировать любые числа из одной системы измерения в другую. Доступны конвертации масс, длин и температур (абсолютный ноль запрещён)

python -m --help - узнать обо всех возможных программах Toolkit

Пользуйтесь на здоровье!
